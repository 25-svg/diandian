典典直播切片 完整离线安装版 v2.20.0
====================================

一、安装

1. 将收到的“典典直播切片-完整离线安装.exe”复制到本机磁盘。
2. 双击 EXE，确认安装提示。
3. 如果 Windows 弹出安全提示，选择【更多信息】→【仍要运行】。
4. 安装完成后软件自动打开，并在桌面生成快捷方式。

无需另外安装 Node.js、Rust、Python、FFmpeg、FunASR、Whisper 或数据库。
安装包已包含本地语音识别服务、中文模型、Whisper 备用模型和 WebView2 离线安装器。

二、保存位置

电脑有 D 盘时，默认目录为 D:\典典直播切片：

- 应用：D:\典典直播切片\应用
- 录播和切片：D:\典典直播切片\录播与切片
- 缓存：D:\典典直播切片\缓存
- 企业知识库：D:\典典直播切片\知识库

少量配置和数据库索引保存在当前 Windows 用户的 AppData 中。

三、首次使用

1. 打开“录播”或“切片”页面，导入测试视频。
2. TS 和 MP4 均可处理；TS 可直接预览，导出切片时由内置 FFmpeg 处理。
3. 点击分析或生成字幕。系统优先使用包内 FunASR，Whisper 作为备用。
4. 首次转写会启动本地模型，可能需要几十秒；后续任务会更快。
5. 云端 AI 分析需要在软件设置中填写本单位自己的 API Key。安装包不会内置或传播私人密钥。

四、注意事项

- 当前安装包支持 64 位 Windows 10/11。
- 安装包体积较大，因为已包含离线语音识别环境和模型。
- 长时间录制时不要退出软件，也不要让电脑进入睡眠。
- 公司数据、API Key、直播账号等由每台电脑自行配置。

五、出现问题时提供

1. 完整错误提示截图。
2. 当时执行的操作。
3. 视频时长和格式。
4. 问题发生的大致时间。
5. D:\典典直播切片\安装日志 下对应时间的日志文件。
