# 企业逐字稿与母稿处理规则 V1

## 数据分层

1. ASR 原稿：保留接口原始结果和时间戳，不覆盖。
2. 系统校正稿：只应用公司已确认参数卡、热词和替换词，并记录每次变化。
3. 人工确认稿：直播负责人逐条确认关键商品事实后形成，是片段分析的唯一输入。
4. 企业母稿：由整场基准直播生成，保留主播原话、商品章节、来源时间和版本。
5. 候选辅稿：其他直播中评分不低于 85 分且通过硬门槛的高光片段。

## 不可自动改写的内容

- 商品名称、型号、规格、价格、成色、库存、优惠、链接号。
- 主播承诺、售后条件、时效和合规表述。
- 无法从逐字稿或公司参数卡证明的事实。

模型可以修正断句、空格、明显同音词和上下文衔接，但关键商业事实必须有来源；存在冲突时标记待确认，不得猜测。

## 母稿对比规则

- 当前已发布母稿是唯一评分基准。
- 系统优先按商品卡 ID 自动匹配，其次按商品型号和章节标题匹配。
- 无法唯一匹配时暂停评分，不允许操作员凭感觉选择章节。
- 总分不低于 85 分且商品、价格、承诺、证据等硬门槛全部通过，才进入候选辅稿队列。
- 候选辅稿经人工审核后才能合并，并生成新的母稿版本；旧版本永久保留。
