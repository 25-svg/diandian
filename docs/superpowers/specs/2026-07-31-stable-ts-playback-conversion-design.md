# TS 自动转码无闪烁播放设计

## 目标

导入不适合浏览器播放的 TS 文件后，自动在后台生成 H.264 MP4；转码过程保持播放区稳定，完成时只切换一次到新文件。

## 原因

当前播放状态使用条件渲染：TS 需要转码时展示占位内容，播放源可用时挂载 `video`。自动启动、轮询状态更新和换源如果交错，会使 `video` 节点被销毁并重建，表现为闪烁。

## 设计

1. 首次检测到 TS 需要可播放副本时，自动排入已有 `prepare_video_playback` 后台任务；同一视频已有进行中的任务则复用。
2. 转码中只渲染固定尺寸的加载占位层，不给 `video` 写入原始 TS URL，也不销毁/重建占位层。
3. 轮询只更新进度文本；仅在后端确认 MP4 任务成功且副本存在后，原子设置最终 URL 和文件键。
4. 最终 MP4 的 `video` 节点只挂载一次；不自动播放，保留用户手动点击播放的控制权。
5. 转码失败时保留稳定占位层并显示失败原因和重试按钮；原始 TS 与已有播放副本不删除。

## 验收

- 打开 TS 分析页后自动创建或复用一个转码任务。
- 转码期间没有原始 TS 播放器挂载，播放区域不闪烁。
- MP4 就绪后播放区仅切换一次，播放器可正常打开。
- 相同视频多次初始化不会创建重复任务。
