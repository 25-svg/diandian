# 录播批量选择 macOS 风格设计

## 目标

让不熟悉系统的用户可以快速看懂、选中并批量删除录播，同时保持当前桌面应用的苹果风格。

## 交互

- 点击录播行的非操作区域切换选中状态。
- 行内播放、生成切片、删除等操作按钮不触发行选择。
- 复选框视觉尺寸为 20px，可点击区域至少为 40px。
- `Ctrl` 点击支持逐项多选；`Shift` 点击支持连续范围选择。
- 表头提供全选复选框，支持全选当前筛选结果及取消全选。
- 有选中项时，窗口底部显示固定批量操作栏，包含选中数量、取消选择和批量删除。
- 批量删除继续使用现有二次确认，并调用已实现的分组批量删除接口。

## 视觉

- 默认行保持白色或现有深色背景。
- 悬停行使用轻微灰色背景。
- 选中行使用浅蓝背景、蓝色内描边和明显蓝色勾选框。
- 批量操作栏使用半透明白色背景、细边框和轻阴影，删除按钮保持红色危险操作语义。
- 不使用大圆角卡片，不改变现有表格信息密度。

## 边界情况

- 点击链接和操作按钮不得改变选择状态。
- 筛选或重新加载后，移除已经不在当前结果中的选择项。
- 删除部分失败时重新加载列表，并保留明确的失败提示。
- 正在录制或被播放窗口占用的录播仍由后端拒绝删除。

## 验收

- 单击整行可选中和取消选中。
- 操作按钮不会误选中行。
- 连选、多选、全选和取消选择可用。
- 选中状态无需仔细寻找复选框即可识别。
- 1280x720 与 1920x1080 下批量操作栏不遮挡列表主要内容。
