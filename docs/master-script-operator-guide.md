# 直播负责人操作说明

## 首次建立企业母稿

1. 导入完整基准直播视频。
2. 勾选“导入后作为整场直播母稿”。
3. 等待分段转写完成，处理系统标出的关键商品事实。
4. 检查商品章节和主播原话预览，确认后发布 V1.0。

本项目首个母稿来源为：

`C:\Users\10230\Downloads\Video\直播大屏·专业版_4.ts`

该文件约 8.8 GB，只需正式导入一次。中断后应使用续跑，不要重复创建母稿。

## 每场直播复盘

1. 直播结束后打开当天录播。
2. 点击“分析片段”。
3. 系统生成并校正逐字稿，发现高光后自动匹配当前母稿商品章节。
4. 右侧查看母稿对比分数、优点、风险和建议插入位置。
5. 分数不低于 85 且规则通过的片段自动进入候选辅稿。
6. 在候选辅稿队列逐条选择“通过、退回或驳回”。
7. 通过的片段在版本差异页确认后，发布为母稿新版本。

页面不要求选择母稿位置。无法识别商品时，系统暂停该片段入库，并提示先校正逐字稿中的商品名称。

## 结果含义

- 已进入候选辅稿：满足分数和硬门槛，等待人工审核。
- 仅保留复盘：内容有参考价值，但未达到 85 分。
- 暂不能进入候选辅稿：存在商品事实、证据或合规问题。
- 商品待确认：系统无法唯一定位母稿商品，不会自动入库。
