## 解析与 UI 约束

1. **禁止**将 `直播间用户支付金额` 显示为「直播间成交金额」。
2. **禁止**伪造图二中 XLSX 没有的指标（含分钟曲线）。
3. `成交件数` 场次汇总：仅对商品汇总行（非 SKU 子行）求和。
4. 缺失字段 UI 显示 `—`，副文案「官方导出未提供」。
5. 百分比存小数（0.0068），展示为 0.68%。
6. 金额存分（23655200），展示为 ¥236,552。
